# Best Time to Buy and Sell Stock

**Platform:** [LeetCode](https://leetcode.com/problems/best-time-to-buy-and-sell-stock/)  
**Topic:** Arrays, Greedy Algorithm

## Problem Overview
Given an array `prices`, where `prices[i]` represents the stock price on the `i`th day, find the maximum profit possible by buying once and selling later. If no profit is possible, return `0`.

## Example
- **Input:** `prices = [7, 1, 5, 3, 6, 4]`
- **Output:** `5`
- **Explanation:** Buy at price `1` and sell later at price `6`, resulting in a profit of `6 - 1 = 5`.

## What You'll Learn
- Traversing arrays while tracking the minimum value.
- Applying a greedy approach to maximize profit.
- Solving the problem in linear time with constant extra space.

**Goal:** Find the best buying and selling opportunity while ensuring the buy happens before the sell.
