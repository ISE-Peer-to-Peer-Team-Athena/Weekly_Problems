# Valid Palindrome

**Platform:** [LeetCode](https://leetcode.com/problems/valid-palindrome/)  
**Topic:** Strings, Two Pointers

## Problem Overview
Determine whether a string is a palindrome after converting uppercase letters to lowercase and ignoring all non-alphanumeric characters.

## Example
- **Input:** `"A man, a plan, a canal: Panama"`
- **Output:** `true`
- **Explanation:** After removing spaces and punctuation and ignoring case, the string reads the same forward and backward.

## What You'll Learn
- String traversal and character comparison.
- Using two pointers to compare characters from both ends.
- Handling spaces, punctuation, and uppercase letters.

**Goal:** Check whether a string reads identically in both directions under the given rules.
