# Two Sum

**Platform:** [LeetCode](https://leetcode.com/problems/two-sum/)  
**Topic:** Arrays, Hashing

## Problem Overview
Given an array of integers `nums` and an integer `target`, find the indices of the two numbers whose sum equals the target. You cannot use the same element twice.

## Example
- **Input:** `nums = [2, 7, 11, 15]`, `target = 9`
- **Output:** `[0, 1]`
- **Explanation:** `nums[0] + nums[1] = 2 + 7 = 9`.

## What You'll Learn
- Traversing arrays and identifying pairs.
- Using hashing to improve search efficiency.
- Understanding indices and target-based conditions.

**Goal:** Find the required pair efficiently instead of checking every possible combination.
